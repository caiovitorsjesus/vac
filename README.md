# vac — Monitor de faltas e notas

Estudantes precisam transformar dados acadêmicos em decisões práticas: **quantas horas ainda podem faltar** e **qual nota precisam tirar** para atingir a média mínima. O vac organiza disciplinas, ausências e avaliações e calcula a situação atual de forma transparente.

> O vac é um organizador e simulador. As regras (limite de faltas, média mínima, nota máxima) são configuradas pelo próprio estudante e não substituem o regulamento da instituição.
